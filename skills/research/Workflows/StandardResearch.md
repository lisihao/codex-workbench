# Standard research

Use this workflow for one bounded, source-dependent decision.

1. State the decision, required evidence, freshness requirement, and stopping condition.
2. Inspect relevant repository or local runtime facts before searching, when they are available.
3. Locate primary sources for each material claim. Open and verify every delivered URL using the URL verification protocol.
4. Cross-check high-impact claims with a second independent source when practical. Do not create extra research agents solely because the question is difficult.
5. Separate source facts, engineering inference, and unknowns. Preserve contradictory evidence.
6. Produce a concise decision-oriented synthesis with the claim ledger and the smallest falsifiable next check.

Stop when the evidence can distinguish the viable options or when the remaining uncertainty is explicitly external. Do not continue collecting redundant sources after the stopping condition is met.
